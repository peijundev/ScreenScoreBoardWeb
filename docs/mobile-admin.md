# 手机管理端

管理端在窄屏（≤ 860px）下自动切换为手机布局。先用账号登录，再按角色显示功能：

- **管理员**：现场记分、人员/团队管理、项目切换、倒计时、排版设置、主题库、主题工作室（含矢量/控件/脚本/TOML/JSON/预览）与数据工具。
- **操作员**：项目切换、人员/团队记分与撤销；不能新增/改名/删除人员、不能重置分数、倒计时、设置、主题或资源库。
- **队员**：只显示「操作 / 更多」两个标签。账号绑定项目与人员，操作页是管理员为该队员单独配置的大按钮（加分/加票、突显）；更多页只有账号信息与退出登录。桌面与手机都使用同一套两栏界面。
- **只读**：可以查看管理端与预览，不能记分。

## 队员控制台与人员功能菜单

队员账号必须绑定一个项目与该项目中的一名人员（「账号与安全 → 用户管理」创建时选择，之后可在用户行里修改绑定）。登录后账号固定使用绑定项目，不能切换项目。

管理员在管理端顶栏（手机端在「更多」）点击「人员菜单」，打开全屏编辑器：

- 左侧列出当前项目中所有绑定人员的队员账号，**每个队员单独配置一份菜单**。
- 可开关整个队员控制台（关闭后队员回退现有只读管理端）；每个队员还可单独启用/停用其菜单，并调整按钮列数（1–4）与间距（0–48 px）。
- 每个按钮可配置文字、启用/停用、动作（加分/加票或突显）、固定目标人员/团队、分值或突显时长、高度、字号、圆角、底色、文字色与背景图。
- 每个按钮还可勾选「仅抢答时启用」：未开始抢答时该按钮不可用；抢答开放期间，勾选「参与抢答」的按钮按下算抢答（第一个按下的获胜），取消「参与抢答」的按钮按下执行原动作（适合投票 / 评分）。
- 列数为 1 且只有一个按钮时，可选择「铺满屏幕 → 自适应」，让按钮按可用区域伸缩，适配平板、横竖屏等不同尺寸；所有尺寸滑条旁都提供数字输入框，可直接输入精确值。
- 右侧「队员端预览」直接复用真实队员界面组件，可切换「操作 / 更多」；加分预览不会写入分数。抢答开始/结束后可在管理端「显示端预览」查看真实计时器与锁定突显。
- 服务端只接受按钮 ID，动作与目标完全取自当前项目中该账号的菜单配置，并校验账号绑定的项目必须与请求项目一致；队员直接调用记分/突显/设置 op 会被拒绝。
- 目标人员/团队被删除后按钮保留并显示警告，执行时返回可读错误；需要管理员重新选择目标或删除按钮。

## 一键暂停队员按钮 / 批量停用队员账号

管理端「显示端预览」顶部的「队员」控制条提供两个独立能力：

- **暂停所有队员按钮**（项目级开关 `memberButtonsPaused`）：只影响当前项目。暂停后服务端同时拒绝 `memberAction` 与 `buzzPress`，队员端显示「队员按钮已暂停」；恢复后立即可用。
- **停用 / 启用所有队员账号**：把全部 `role=member` 的账号标记为停用或恢复。停用会立即吊销这些账号的会话与令牌，队员需要重新登录；**这是全局操作，会影响其他项目里的队员账号**。管理员账号不受影响。

## 抢答模式

同一「人员功能菜单」对话框顶部提供项目级抢答设置（不是按队员菜单）：

- 启用抢答、计时器模式（`prepare` 先准备倒计时再开放 / `window` 倒计时期间抢答）、倒计时秒数、赢家突显目标（本人 / 所属团队）、抢到后加分、可抢按钮范围（全部启用按钮 / 仅勾选「参与抢答」的按钮）、抢到后执行按钮原加分动作、输家提示、抢到即关闭计时器。
- 开始 / 结束按钮位于管理端「显示端预览」面板。开始后联动现有倒计时：倒计时外观沿用项目的倒计时设置；即使项目关闭了「倒计时」，抢答期间也会临时显示，到 0 自动关闭，不修改项目开关。
- 服务端串行处理抢答，只有第一个有效按下的人获胜；之后所有抢答请求返回「已被抢答」。赢家在大屏以锁定突显停留在中央，不自动退回，直到管理员点「结束抢答」。
- `prepare` 模式到 0 后开放抢答，之后无额外时限，由管理员结束；`window` 模式抢到即锁定（可关闭「抢到即关闭计时器」让倒计时继续）。
- 「倒计时结束后显示『开始抢答』」默认开启：准备倒计时结束后计时器保留并显示提示，直到有人抢到；可在人员功能菜单关闭。
- 普通队员按钮在抢答进行中会被禁用；结束后恢复原本的加分/突显动作。勾选「仅抢答时启用」的按钮只在抢答开放期间可用。

## 打开方式

1. 电脑启动计分板：`npm start`
2. 手机与电脑连同一局域网
3. 手机浏览器打开 `http://<电脑局域网 IP>:3000/admin`
4. 输入账号密码登录（首次使用请先由管理员创建操作员账号）

大屏显示端仍然只建议在电脑/投影上打开 `/display`，显示端公开只读、无需登录。

## 布局

- **顶栏**：项目选择、撤销、实时连接状态
- **底部标签**：`预览 / 人员 / 团队 / 外观 / 更多`
- **面板常驻、只显示当前标签**：切 tab 用 CSS 隐藏，保留输入内容与预览状态，同时避免重复挂载长列表
- **对话框全屏**：所有设置、批量添加、主题工作室在手机上铺满 `100dvh`，标题栏固定在顶部，并适配刘海/安全区
- **触控目标**：默认最小 44px，可在「排版设置 → 管理端」调整到 40–64px

### 各标签功能

| 标签 | 内容 |
|---|---|
| 预览 | 实时预览大屏；「平移」按钮进入拖动模式；管理员可直接开始/暂停/继续/重置倒计时，并可启用倒计时功能 |
| 人员 | 搜索；管理员可新增、批量添加、改名、简介、头像/卡面、团队、排序、删除；操作员保留加减分与撤销 |
| 团队 | 管理员可团队 CRUD、成员管理；操作员保留团队加减分 |
| 外观 | 仅管理员可见的「外观设置」：排版设置、主题编辑器、主题工作室 |
| 更多 | 管理员可见项目 CRUD、功能开关与数据、资源库、人员菜单、存储后端；所有角色可见管理端深浅色、打开显示端、账号与安全、退出登录 |

## 触屏操作

- 常规点击：按钮与列表项均已放大到触控尺寸
- 预览平移：点「平移」切换模式，直接拖动；再点一次退出，不依赖键盘 Alt
- 主题工作室矢量：工具栏「约束」开关等价于桌面按住 Shift；选中手柄在手机上自动放大
- 所有改名、删除确认、简介编辑都使用应用内对话框，不触发浏览器原生 `prompt/confirm`（部分手机浏览器会屏蔽或样式不可控）

## 新增设置

| 设置键 | 默认 | 范围 | 作用 |
|---|---|---|---|
| `featureMobileAdmin` | `true` | 布尔 | 关闭后手机也强制使用桌面布局，作为回滚保险 |
| `adminTouchTargetSize` | `44` | 40–64 | 手机管理端最小触控目标边长（px） |

两项都在「排版设置 → 管理端」分组。显示端没有对应语义，`applyAppearance` 会显式跳过并注释。设置经过服务端校验、契约生成与重启恢复测试。

## 已知边界

- 手机布局通过 `useMediaQuery` 条件渲染，桌面 DOM/交互保持原路径；宽度跨过 860px 时会重挂载管理端外壳
- 人员极多时未做虚拟列表，依靠「面板隐藏 + 搜索过滤」控制开销；需要时可先搜索再操作
- 主题工作室在手机上仍是密集编辑界面，复杂主题建议横屏或桌面编辑
- 预览 iframe 在部分旧版手机浏览器上可能限制同源脚本，若预览空白请升级浏览器

## 验证

```bash
npm run build:web          # 需要先有 public/v2/
npm run test:mobile        # 无 Chromium 时自动 skip
```

自动化用例在 390×844 下检查：登录管理员、无横向溢出、5 个底部标签（含「外观」）、新增人员并加分、外观页的主题工作室全屏且 8 个标签、矢量 SVG 可用、排版设置全屏、预览计时器可开始/暂停/重置。

## 零项目欢迎页与主题

- 没有任何项目时，管理端不再强制创建默认项目，而是显示 VSCode 风格欢迎页：新建项目、导入项目、整库导入、打开显示端、最近项目，以及管理端主题和账号入口。
- 管理端默认主题为 **macOS 浅色**；可在欢迎页、顶栏「界面」或手机端「更多 → 显示」中切换。
- 队员账号的「更多」页也提供管理端主题选择，队员可以自行切换界面主题。
- 显示端在没有项目时显示「尚未创建项目」等待画面，而不是空白或一直连接中。

## 团队卡片模式（突显与加分）

在「排版设置 → 特效 → 团队卡片模式」中可选择：

- **团队卡片**（默认）：突显团队时只显示团队名称 + 头像，不展开成员；团队加分作用于全队每位成员。
- **队长卡片**：显示队长姓名 + 头像与团队名称；没有队长时回退团队卡片；团队加分只作用于队长。

该设置同时作用于手动/API 突显、抢答赢家突显，以及团队整体加分（包括快捷分、任意分值与抢答团队加分）。
